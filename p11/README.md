# P11 — „Widget-Dashboard"

Projekt des ASPICE-Teams (beauftragt via `pm/T-0033`, Option **G0a**, `pm/D007` → `p11/D000`):
eine **kompakte, nicht scrollbare Übersichtsfläche** in Mission Control, die alle Projekte und
Teams als konfigurierbare **Widgets** zeigt — Startseite plus eigene Seite je Projekt/Team, dazu
ein **Mail-Widget** hinter dem bestehenden PIN-Lesegate.

**Fachlicher Auftraggeber und Abnehmer ist `team-dashboard`** (gegründet mit `pm/D006`/TG-a);
gebaut wird von ASPICE. Das Projekt lebt als Ordner im Sammel-Repo `projects` (`pm/D003`).

**Eingangsbedingung für Sprint 1, nicht Teil dieses Projekts:** der **Widget-Vertrag**
(`team-dashboard/T-0001`, Frist 23.08.) — welche Felder ein Projekt/Team überhaupt liefert.
