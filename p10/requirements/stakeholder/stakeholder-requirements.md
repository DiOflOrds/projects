# Stakeholder Requirements — P10 „Aufgaben bearbeiten im HMI"

*v1.0, 2026-08-16 (RM). Source: pm/N-0013 + pm/N-0014 + pm/T-0011 (P10a, pm/D005). Language: English (D011).*

| ID | Requirement | Source | Status |
|---|---|---|---|
| STK-020 | As the client I want to edit my open tasks directly in Mission Control — change what a task says, what type it is, how urgent it is and which team or project it belongs to, using freely chosen labels I can filter the board by — so that I no longer have to write a letter and wait for the next session to reorder my own work; and I want the system to tell me plainly when the team changed the same task in the meantime, instead of one of us silently overwriting the other. | pm/N-0013, pm/N-0014 | reviewed |
